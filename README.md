# 角色三视图 → 360° 环绕展示视频提示词工程

> 基于 **Seedance 2.0（Seedance 2.0 Mini / Fast，即梦网页端 / Ark API）** 的图生视频提示词编排 Skill。
> 输入单角色正 / 侧 / 背全身立绘三视图，输出一套可直接粘贴到平台的「固定姿态 + 镜头匀速 360° 环绕」展示视频执行包。

---

## 1. 项目简介

本工程解决一个具体问题：**让角色"自己不动，只由镜头绕它转一整圈"**，产出一镜到底、首尾闭环、无音频无文字的角色展示片（转盘展示 / 人设展示 / 电商与虚拟形象宣传片）。

- **输入**：单角色三视图（正面 / 侧面 / 背面全身立绘，非写实真人脸风格）。
- **输出**：按 Seedance 2.0 真实参数组织好的交付包 —— 参数确认 + 正向提示词 + 负向提示词（通道支持时）+ 时间戳分镜表 + 生成前自检清单；出片后另有抽帧 QA 流程。
- **核心约束**：单主体、单镜头、一镜到底、角色全片零肢体动作、运动只来自镜头环绕视差、0 秒与尾帧回到同一正面机位并精确转满 360°。
- **不负责**：在平台侧实际点击生成、成片后期抠像 / despill、以及三视图本身的绘制（上游三视图提示词见各示例 `说明.txt`）。

技能主文件为 `SKILL.md`（当前 v1.2.0），内含全部可直接粘贴的英文载荷与规则。

---

## 2. 适用场景与触发词

当出现以下意图时使用本工程：

- MiniMax H3 官方图生视频本地部署360环绕模型生成效果还差一些；
- Seedance 2.0 / 即梦 / `doubao-seedance` 图生视频、文生视频提示词编写；
- 三视图转视频、角色 360° 环绕展示、转盘展示、人物 / 服装展示片；
- 需要"角色冻结、镜头环绕、首尾闭环、干净幕布、静音无字幕"的标准展示镜头。

**目标用户**：角色设计、虚拟形象运营、电商与二次元内容创作者、短视频与展示片制作人员、需要批量出人设展示片的美术与运营。

**使用前置**：

1. 自备单角色正 / 侧 / 背全身立绘（**不得为写实真人脸照片**，否则平台会拦截；须为 2.5D / 3D / 插画风格）；
2. 具备 Seedance 2.0（即梦网页端或 Ark API）账号与生成额度；
3. 自行完成三视图切图（剔除标签、表情卡、特写卡）并在平台侧粘贴参数与提示词完成生成。

## 3. 主要功能点

| 模块 | 能力 |
|---|---|
| 素材处理 | 三视图切单图；素材角色映射（正面→首尾帧 / 姿态基准，侧面 / 背面→仅外观参考）；每张素材配用途句，防止模型混淆图、角色与用途 |
| 幕布决策 | 绿 / 蓝 / 白 / 灰四色推荐矩阵；先输出首选 + 备选 + 不推荐及理由，**经用户确认后锁定**；正向、负向、参数、分镜、交付说明五处字面一致 |
| 姿态冻结 | 肢体零动作提示词（含非持物手绝对下垂、角色不自行旋转）；单一冻结姿态；道具持法（手 / 高度 / 朝向）写死并禁止换手、移肘、摆动 |
| 运镜控制 | 匀速整圈四量（起始正面、结束精确正面、总 yaw=360°、恒定角速度）；5 秒 / 72° 每秒的时间—角度对照与时间戳分镜 |
| 写实锚定 | 真人实拍电影质感参数置顶，负向重罚动漫 / 3D / CGI / 塑料皮肤，压制二次元建模感 |
| 外观一致性 | 逐项外观清单 + 关键"负形（没有什么）"防脑补 + 配件白名单，禁止凭空增减配饰、改变领口 / 裙长 / 开衩 |
| 质量流程 | 生成前逐项自检清单；出片后抽 0s / 1s / 2.5s / 4s / 5s 五帧 QA；单变量原则的迭代重试方案；高频缺陷对照表 |
| 通道降级 | 针对无独立负向字段、无水印开关、无首尾帧参数等通道差异给出降级写法（禁止项并入正向承诺声明、入口 A 降级为 B 全能参考等） |

## 4. 默认生成参数与平台事实

**默认组合**（改动任一项都需写进交付说明）：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 模型档 | `Seedance 2.0 Mini/Fast`；快档 `doubao-seedance-2-0-fast-260128` | Mini 画质优先，Fast 省时略降画质 |
| 时长 `duration` | **5 秒**（平台支持整数 4–15 秒） | 超 15 秒需分段延长并回取末帧衔接 |
| 比例 `ratio` | **3:4 竖屏** | 通道不支持时退 9:16 或 adaptive |
| 分辨率 | **720p**（24fps） | 不支持退 480p；抠像后期优先保 720p；更高清走 2K 通道 |
| 音频 | `generate_audio=false` **且提示词双写"无音频、无配乐、无音效"** | 仅关参数模型仍可能补音效 |
| 水印 | `watermark=false` | 默认 true，关不掉则后期裁切或换通道 |
| 素材数 | 图 ≤9、视频 ≤3 段、音频 ≤3 段；图 + 视频 + 音频合计 ≤12 | 三视图须先切图再传 |

**两条素材入口（二选一，不混用；默认 A）**：

- **A 首尾帧（优先，保姿态）**：首帧 = 尾帧 = 同一张正面全身图，0° 与 360° 由首尾帧钳死；
- **B 全能参考（保背面细节）**：正 / 侧 / 背三张一起传，姿态基准仍只认正面图；通道不支持 A 时强制降级为 B。

## 5. 标准执行流程（不得跳步）

1. **读角色配色** → 输出幕布首选 / 备选 / 不推荐及理由，**等待用户确认**（确认前不得写任何提示词）；
2. 定参数与入口（第 4 节、平台参数表）；
3. 切分三视图单图，并为每张图写素材用途句；
4. 按固定顺序组装正向词：实拍参数置顶 → 技术规格头 → 背景与防溢 → 素材用途 + 外观清单（负形 + 白名单）→ 肢体零动作 + 冻结姿态 + 道具锁定 → 运镜四量 + 时间戳分镜 → 结尾正向承诺声明；
5. 按交付模板产出执行包；
6. 过生成前自检清单；
7. 出片后过抽帧 QA，不合格按"单变量原则"逐项迭代。

**三条硬红线**：

1. 幕布未确认前不产出提示词；
2. 角色全片零肢体动作，唯一运动是镜头环绕视差；
3. 0 秒与尾帧必须是同一正面机位、同一构图与人物尺寸。

## 6. 幕布选择矩阵（锁定后只保留一套正 / 负向）

| 幕布 | 适用主体配色 | 应排除的情况 |
|---|---|---|
| **A 绿幕 #00B140（默认）** | 含白 / 米白 / 黑 / 红 / 紫 / 粉 / 蓝 / 金，发色黑 / 棕 / 金，肤色正常 | 主体大面积绿 / 黄绿 / 青绿、发色鲜绿 |
| **C 蓝幕 #0047BB** | 含绿 / 黄绿 / 青绿、鲜黄、橙；发色黑 / 棕 | 主体大面积蓝 / 青 / 深蓝、发色鲜蓝 |
| **B 白幕（纯白无缝）** | 深色 / 高饱和主体，且要求直接成片不抠像 | 主体含白 / 米白 / 奶白 / 浅灰 / 银白 / 白蕾丝网纱，或需要抠像 |
| **D 灰幕 #808080** | 纯白与纯黑同时大面积出现、需中性直出 | 后期要抠像、主体大面积灰 / 银灰 |

> 铁律：不得"正向写绿幕、交付给白幕"；锁定后另一套幕布的正 / 负向词必须删净。绿 / 蓝幕须写离幕距离（≥1.5m）、中性白轮廓光、`no spill`，并对浅色缎面、蕾丝、网纱、白丝绸等高风险材质标注后期 despill。

## 7. 运镜与分镜规格（5 秒 / 72° 每秒）

| 时间 | 累计角度 | 应呈现画面 |
|---|---|---|
| 0.0s | 0° | 正面全身居中（首帧 = 尾帧） |
| 0.5s | 36° | 正面偏侧，首秒内须可见角度变化 |
| 1.0s | 72° | 明显 3/4 侧 |
| 1.5s | ≈90° | 正侧面 |
| 2.5s | **180°** | **正背面**（背面细节揭示节点） |
| 4.0s | 288° | 另一侧 3/4 |
| 5.0s | **360°** | **精确回正面，闭环定格** |

分镜固定为 B01（0–1s，0°→72°）、B02（1–3s，72°→216°，2.5s 正对背面）、B03（3–5s，216°→360° 回正）三段；**分镜主语必须是镜头**，不得出现转身 / 走动 / 抬手等角色动作动词。运镜禁止过转 / 欠转、多圈 / 少圈、变速、缓入缓出、停顿、变焦、推拉、切镜、手持抖动与反向旋转。

## 8. 单个角色的交付包结构

每个角色一个文件夹，最终成品 `<角色>.md` 由以下板块构成（与 `SKILL.md` 第 9 节模板一致）：

1. **视频生成参数确认**：模型档、入口 A/B、时长 / 比例 / 分辨率、静音与水印处理、素材映射、已确认幕布、风格锚定、冻结姿态与持法、主线与首尾节点；
2. **正向提示词**（整段直接粘贴，固定顺序组装）；
3. **负向提示词**（仅通道支持 `negative_prompt` 字段时填写；无字段则跳过，约束并入末尾正向承诺声明）；
4. **时间戳分镜表**（三行，镜头主语，角度对齐第 7 节）；
5. **生成前自检清单**（逐项打勾，含幕布一致性、防溢、平台限制、姿态冻结、外观白名单 / 负形、静音双写等）。

提示词写作要点：正向词末尾使用"绝对承诺"句式（不写"禁止 XX"，避免注意力被 XX 吸引）；外观必须写关键负形（如"腹部无横带"）与配件白名单（如"仅允许 X，绝不出现 Y"）。

## 11. 出片 QA 与迭代原则

**抽帧检查点**：0s / 1s / 2.5s / 4s / 5s，任一不合格即重做，重点看：

1. **写实度（最高优先级）**：是否滑向 3D 建模 / 二次元；皮肤是否有真人毛孔质感而非塑料；
2. **肢体**：非持物手是否抬起 / 摸包 / 摸腰；持物手高度朝向是否位移；
3. **服装变异**：领口形状、腹部横带、开衩位置、裙长是否漂移；
4. **配饰增减**：是否凭空多出手链戒指，或丢失脚链 / 项链；改手提后是否残留肩带；
5. **闭环**：0s 与 5s 构图、站位、尺寸是否一致；累计是否转满 360°（<340° 或 >380° 不合格）；
6. **防溢**：网纱、系带、丝巾边缘是否残留绿 / 蓝边；
7. **静音与水印**：音轨是否真无声、画面是否带平台水印。

**迭代原则（单变量）**：每次只改 1–2 个关键词、只修一个问题，不整段重写。常见修法：动漫 / 3D 感 → 实拍参数置顶 + 负向叠加 `3D render, CGI, plastic skin`；动作过多 → 肢体冻结段前置并补 `idle motion, swaying body`；整圈不闭合 → 改入口 A（首=尾=正面图）；服装变异 → 负形句提至外观清单最前并全大写；防溢不干净 → 增大离幕距离描述或改白 / 灰幕直出。连改 2 次不过则降级为"换入口 + 精简外观描述（保留 6–8 个关键项）"。

## 12. 平台硬限制（出稿前必读）

- 不支持上传**写实真人脸**素材（图片 / 视频均会被拦截）；写实化只能写进提示词，不能传真人照片；
- 规避知名 IP / 品牌名，改写为发色、服装结构、道具形制等外观描述；
- 参考视频显著加价，2K 远贵于 720p；**5 秒静音 720p 为最省组合**；
- 单次最长 15 秒，更长环绕须分段生成、以末帧衔接；
- 静音必须"参数关闭 + 提示词声明"双写；水印默认开启，需显式关闭或预留裁切方案；
- 通道能力差异（无负向字段 / 无水印开关 / 无首尾帧参数）须按 `SKILL.md` 第 1.2、1.3 节降级并在交付说明中注明。
